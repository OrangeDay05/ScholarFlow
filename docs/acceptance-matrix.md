# 论文 AI 系统 V0.3 验收矩阵

文档状态：M7 V0.5.1 实现完成，等待审核；M5 真实供应商端到端待专用测试凭据

适用版本：V0.3 简易通版

更新时间：2026-07-28

## 1. 使用规则

- 本矩阵把需求改写为可执行、可观察的验收项。
- `目标里程碑` 表示最迟应完成并提交证据的阶段，不表示当前已经实现。
- M1/M2 的 Mock 能力只能以 `Mock` 验收，不能作为真实业务能力通过。
- M2 条目只按前端 Mock 原型验收；真实后端、数据库、AI、文件解析和 DOCX 产物仍按后续目标里程碑保持待实现。
- 每项通过时必须附上代码/测试、浏览器检查、截图、日志或真实产物中的至少一种证据；阶段门要求的证据必须全部提供。

状态统一使用：

- `待实现`：尚未进入实现阶段；
- `待验收`：已有实现但尚无充分证据；
- `通过`：已按本矩阵取得证据；
- `阻塞`：受明确依赖阻塞；
- `不适用`：仅在变更批准后使用并说明原因。

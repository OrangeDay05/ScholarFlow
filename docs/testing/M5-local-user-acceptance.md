# M5 本地真实最小闭环人工验收

当前状态：`WAITING_FOR_USER_CREDENTIAL_CONFIGURATION`

本说明不会要求用户在聊天中提供 DeepSeek API Key。自动测试通过不等于真实 Provider 或完整 AI 修改闭环已经通过。

## 一、启动前准备

1. 在 `E:\论文系统\site\.dev.vars` 配置本地服务器变量：

   ```dotenv
   DEEPSEEK_API_KEY=
   DEEPSEEK_BASE_URL=
   ```

2. `.dev.vars` 已被 `.gitignore` 排除；不要提交或截图其内容。
3. 本地 D1 位于 `E:\论文系统\site\.wrangler\state\v3\d1\`，当前验证链为 0000→0017。
4. 本地材料对象状态位于 `.wrangler` 的本地 R2/Miniflare 状态中。
5. 在 `E:\论文系统\site` 运行 `pnpm.cmd dev`。
6. 配置或修改 `.dev.vars` 后必须重启服务。

## 二、测试账号

打开 `http://localhost:3000/register`，通过注册页面创建只存在于本地开发环境的测试账号。不要使用生产账号或真实用户论文。

## 三、测试材料

建议自行创建 `m5-acceptance-material.txt`，内容为 300—800 字、两段无敏感信息的学术文字，故意包含重复表达、过度结论和术语不一致。不得包含真实姓名、手机号、邮箱、未公开论文或保密数据。

## 五、错误场景

- 未配置 Key：显示需要配置，不调用 Provider。
- Key 错误、超时、额度不足、模型不可用：显示统一安全错误，不返回 Key、响应原文或堆栈。
- 用户取消、预算不足：不追加调用，不自动恢复或切换模型。
- 材料丢失、基础版本变化：阻断执行并要求重新确认。
- 候选生成失败：任务不得标记成功，已完成步骤和原版本保留。

# 论文 AI 系统 V0.3 项目章程

## 项目目标

以“论文项目管理 + 材料解析 + 项目诊断 + 章节工作流 + 文献知识库 + 引用证据 + 版本管理 + DOCX 导出”为核心，分阶段交付可验证的中文学术 SaaS。

## 当前授权范围

- 当前仅执行 M0 与 M1。
- M1 只建设前端视觉基线和页面骨架，使用明确标注的 Mock 数据。
- M1 审核前不建设正式数据库、业务后端、文件解析器、AI Provider、真实 Skill 集成或生产部署。
- M1 审核后必须停止，等待用户明确批准。

## 成功标准

1. 明确唯一活动工程。
2. 建立项目治理、范围、风险、变更和验收文档。
3. 真实渲染登录、项目列表、五种创建方式、Idea 表单、诊断卡和三栏编辑器。
4. 六个产品级 Skill 名称正确且不暴露内部 Skill。
5. 不出现 V0.3 排除功能入口。
6. 形成桌面与窄屏截图、浏览器检查结果和 M1 审核包。

## 角色

- 用户：产品决策者与阶段门批准人。
- Root Agent：项目经理、产品负责人、技术负责人、质量负责人和集成负责人。
- 子 Agent：只在同一里程碑内按互斥目录所有权执行任务。

## 治理规则

- 需求主依据：`论文AI系统需求说明_V0.3_简易通版.md`。
- Skill 映射依据：`给系统开发Agent的Skill集成说明.md`。
- 开发推进依据：`论文AI系统_Codex阶段门控项目管理开发指令_V1.0.txt`。
- 任何范围、视觉基线或数据契约变化必须登记变更。
- 生产部署仅在用户明确要求后进入 M8。

## 当前阶段

- 当前里程碑：M0 项目启动与工程基线。
- 下一阶段：M1 前端视觉基线与核心页面骨架。
- 首次阶段门：M1 审核。

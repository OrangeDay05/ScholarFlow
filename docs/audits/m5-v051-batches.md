日期：2026-07-28

状态：`M5_IN_PROGRESS`

## 1. 起点

- M4 已通过，CORE-01、I-015 和 I-016 已解除。
- M4 已提供项目/材料/诊断/任务/隐私/模型/PPT 数据契约、Repository、API、所有者隔离和 0000→0005 迁移链。
- M5 不能把 M3 Mock 或已安装 Skill 直接称为真实能力；每项真实能力必须有 Adapter、持久化、失败状态、权限边界和测试证据。
- OpenAI 作为默认生成供应商、DeepSeek 作为备用供应商；没有平台或用户凭据时不得发起调用或伪装成功。
- Nature Review Studio 继续默认关闭，直到 DOCX 输出契约、依赖和隐私审计问题单独解决。

## 3. 小批次

### M5-B1：真实执行共享契约

- 目标：冻结六 Skill 输入输出、Provider Adapter、凭据解析、调用上限、超时和恢复边界。
- 依赖：M4-H2。
- 修改：`app/lib/m5-*.ts`、`tests/m5-*.test.mjs`、项目管理文档。
- 数据模型/API：本批不迁移、不新增 API。
- 测试：TypeScript、局部 ESLint、契约测试、既有回归。
- 验收：无明文凭据；六 Skill 不增不减；2/3/4 模型与 2/4/5 调用上限；章节写作诊断门；任务恢复分类明确。
- 风险：把接口误报为真实调用。
- 停止条件：契约与 M4 状态机或隐私门冲突。

### M5-B2：真实文件与项目知识库

- 目标：上传、对象存储、PDF/DOCX/TXT/XLSX/CSV/图片/BibTeX/RIS 解析、解析版本和分段索引。
- 依赖：B1、对象存储选择。
- 修改：`app/api/m5/materials/**`、`app/lib/parsers/**`、`db/**`、`drizzle/**`。
- 测试：每种格式夹具、损坏/加密/超限文件、权限和解析失败。
- 验收：原文件保留；新解析不覆盖；位置可追踪；失败不伪装成功。
- 风险：OCR/复杂布局准确率、文件炸弹、对象存储配置。
- 停止条件：供应商或存储未确定、解析破坏原文件。

拆分执行：

- M5-B2A（DONE）：Storage Adapter、本地持久化 R2、上传安全、0006 对象记录、Session 隔离、补偿与最小 UI；文件只到 `AWAITING_PARSE`。
- M5-B2B（PENDING）：TXT、CSV、BibTeX、RIS 解析版本与来源位置。
- M5-B2C（PENDING）：DOCX 与文本型 PDF；扫描 PDF/OCR 明确不冒充支持。
- M5-B2D（PENDING）：XLSX 结构与图片资产登记，不执行公式、宏或复杂图像理解。
- M5-B2E（PENDING）：ParseRun、Chunk、来源定位和项目知识库检索。
- M5-B2F（PENDING）：权限、隔离、失败恢复、孤立对象维护与完整回归。

M5-B1 follow-up：M5-FU-01 必须在 B4 Runner 前解决；M5-FU-02 必须在 B3 Provider Adapter 前解决。B2A 只登记，未扩大实现范围。

### M5-B3：加密凭据与 Provider Adapter

- 目标：平台凭据、用户 Key 服务端加密、连接测试、OpenAI 主模型和 DeepSeek 备用 Adapter。
- 依赖：B1、用户确认密钥与平台凭据策略。
- 修改：`app/api/m5/credentials/**`、`app/lib/providers/**`、`db/**`、`drizzle/**`。
- 测试：密文、掩码、跨用户隔离、错误 Key、超时、限流和日志泄漏扫描。
- 验收：明文不落库/日志/响应；连接测试可撤销；无凭据不调用。
- 风险：密钥泄漏、供应商协议变化、开发环境误用生产 Key。
- 停止条件：无主密钥、无用户明确提交动作、日志出现秘密。

### M5-B4：任务 Runner、预算与恢复

- 目标：可恢复任务执行、幂等、调用预算、取消、超时、限流和失败降级。
- 依赖：B1、B3。
- 修改：`app/lib/tasks/**`、`app/api/m5/tasks/**`、Repository 与事件表。
- 测试：重启、重复请求、部分失败、预算暂停、取消、最大调用次数。
- 验收：成功产物保留；失败不标通过；禁止无限循环。
- 风险：重复计费和重复版本。
- 停止条件：幂等或恢复无法证明。

### M5-B5：动态诊断、Idea 与合法文献发现

- 目标：真实单问题诊断、停止条件、Idea 路由和合法来源候选检索。
- 依赖：B2—B4。
- 修改：诊断 Adapter、外部检索 Adapter、对应 API/UI 增量。
- 测试：连续不知道、材料优先、元数据状态、无来源警告。
- 验收：AI 推测不冒充确认；搜索候选不冒充证据；一次只问一个问题。
- 风险：无限追问和伪文献。
- 停止条件：无法核验来源或超过问题/调用预算。

### M5-B6：六 Skill、多模型与隐私外传

- 目标：六个产品 Skill 的真实顺序执行、生成/审阅/验证/修订/汇总、处理副本和外传前确认。
- 依赖：B2—B5。
- 修改：Skill Adapter、任务 UI、隐私处理和版本 Repository。
- 测试：版本追加、证据警告、用户决定、部分失败和隐私阻断。
- 验收：一个主 Skill；审阅不覆盖正文；无数据不生成结果；外传有明确授权。
- 风险：材料越权、事实幻觉、模型循环。
- 停止条件：证据门、版本门或隐私门失败。

### M5-B7：全量 QA 与审核门

- 目标：权限、隔离、安全、恢复、性能、浏览器流程、文档和审核包。
- 依赖：B1—B6。
- 修改：`tests/**`、`docs/reviews/M5/**`、状态文档。
- 验收：全仓 lint/type/build/E2E 通过；真实能力与未实现能力标识准确；停在 M5 审核门。
- 风险：测试使用真实密钥或产生不可控费用。
- 停止条件：任何密钥泄漏、跨用户访问或不可恢复迁移。

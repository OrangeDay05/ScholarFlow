|---|---|

## 已知验证限制

开发服务器热重启时，浏览器停在连接失败数据页，后续操作被浏览器 URL 安全策略阻断。本轮没有绕过该策略。重启前已确认 M2 页面正常渲染；M3 的 D1 数据来源、隔离、持久化和路由回归由 API、SSR、构建与自动化测试覆盖。D1 标签的视觉复核留待新的浏览器会话。

该限制不影响 Schema、迁移、API 或构建结论，但意味着本轮不能声称“重启后已在浏览器中看到 D1 标签”。
